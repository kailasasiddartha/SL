MARKUP

HTML5 (HyperText Markup Language 5)

Declarative structural backbone for defining semantic content, document trees, and input interfaces.

Tasks: 1A, 1B, 2, 3A, 3B, 4, 5, 6A, 8, 10, 11, 12

Core Definition & Purpose

HTML5 is the standard markup language used to structure content on the World Wide Web. It provides declarative elements that browser layout engines parse into the in-memory Document Object Model (DOM) tree. HTML5 eliminates reliance on legacy browser plugins by introducing native audio/video playback, canvas 2D graphics, and semantic structuring elements.

Essential University Lab Concepts

  • Semantic Architecture: Elements like <header>, <nav>, <main>, <section>, and <footer> replace generic division tags to communicate structural intent to search crawlers and screen readers.
  • Complex Tabular Layouts (Task 1B): Using <table>, <thead>, <tr>, <th>, <td>, along with colspan (horizontal merging) and rowspan (vertical merging) to design college academic timetables.
  • Forms & Input Controls (Tasks 1A, 2, 5, 7B): Constructing interactive input interfaces via <form action="process.php" method="POST"> with text, password, email, radio, checkbox, select dropdowns, and submission buttons.
  • Media Integration: Native integration of multimedia via <img src="..." alt="...">, <audio controls>, and <video controls> without third-party flash players.
How to Execute HTML Documents:
  1. Save source code with a .html or .htm extension.
  2. Double-click the file to open directly in any modern browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
  3. Alternatively, serve locally using VS Code "Live Server" extension or any CLI static web server (npx serve).
  4. Open DevTools (F12) to inspect DOM tree hierarchy and debug layout rendering.
PRESENTATION

CSS3 (Cascading Style Sheets 3)

Declarative stylesheet language for visual presentation, layouts, responsiveness, and typography.

Tasks: 1A, 1B, 2, 4, 5, 6A, 6B, 9

Core Definition & Purpose

CSS defines how HTML elements are formatted, styled, and rendered across different display viewports. The cascade algorithm computes rules based on specificity, inheritance, and source order, ensuring visual consistency across web applications.

Key Stylistic Architecture Concepts

  • Three Insertion Methods: External (<link rel="stylesheet" href="style.css">), Internal (<style> in head), and Inline (style="..."). External is strongly preferred for clean separation of concerns.
  • The CSS Box Model: Every element is treated as a rectangular box consisting of (from inside out): Content → Padding → Border → Margin. Setting box-sizing: border-box; ensures padding and borders are included in total width.
  • Modern Layout Systems:
    • • Flexbox (1D): display: flex; justify-content: space-between; align-items: center; for aligning navigation bars and toolbars.
    • • Grid (2D): display: grid; grid-template-columns: repeat(3, 1fr); gap: 1rem; for complex grid cards.
  • Responsive Media Queries: @media (max-width: 768px) { ... } dynamically adapts layouts for mobile devices.
How to Apply & Debug CSS:
  1. Save rules with a .css extension.
  2. Link inside the HTML <head> tag via <link rel="stylesheet" href="style.css">.
  3. Inspect in DevTools (F12) under the "Computed" and "Styles" panels to verify rule cascade and box model geometry.

JavaScript provides dynamic behavior to web pages. Executed inside the browser's JavaScript engine (e.g. Chrome's V8), it intercepts user events, mutates the live DOM tree without requiring server round-trips, validates user inputs with regular expressions, and manages asynchronous network requests.

DATA STORAGE

XML (eXtensible Markup Language)

Platform-independent, self-describing hierarchical format designed for cross-platform data transport.

Tasks: 9 (Motorbike Catalog)

Core Definition & Purpose

XML was designed by the W3C to store and transport structured data without prescribing visual representation. Unlike HTML, which has predefined tags, XML allows developers to invent custom domain-specific tags that describe data semantics accurately.

The 5 Rules of Well-Formed XML

  1. Single Root Element: All XML content must be enclosed within one singular parent root element.
  2. Mandatory Closing Tags: Every opening tag must possess an explicit closing tag (or self-close <tag />).
  3. Strict Case Sensitivity: Tag names are strictly case-sensitive (<Bike> ≠ <bike>).
  4. Proper Nesting: Tags must never overlap (<b><i>Text</i></b> is valid; <b><i>Text</b></i> is illegal).
  5. Quoted Attribute Values: All attributes must have values surrounded by quotes (id="101").
How to View & Parse XML:

Save as a .xml file and double-click to open in modern browsers. Browsers automatically validate well-formedness and display an expandable/collapsible colored tree view.

VALIDATION GRAMMAR

DTD (Document Type Definition)

Structural schema defining the legal elements, hierarchy, and attributes of an XML document.

Tasks: 9 (Motorbike Schema)

Core Definition & Purpose

A DTD acts as a contract that defines the legal building blocks of an XML document. An XML document that follows the general XML syntax is called Well-Formed. An XML document that conforms to its specific DTD grammar is called Valid.

DTD Syntax & Multiplicity Symbols

  • + (Plus): One or more occurrences (<!ELEMENT catalog (bike+)>).
  • * (Asterisk): Zero or more occurrences.
  • ? (Question Mark): Optional, zero or one occurrence.
  • , (Comma): Ordered sequence ((name, engine, mileage, price)).
  • | (Pipe): Selection / choice (either A or B).
  • #PCDATA: Parsed Character Data (text parsed by XML parser).
  • #REQUIRED vs #IMPLIED: Attribute is mandatory vs optional.
TRANSFORMATION

XSLT (Extensible Stylesheet Language Transformations)

Declarative template transformation language turning XML trees into formatted HTML or documents.

Tasks: 9 (XSL Formatting)

Core Definition & Purpose

XSLT is used to transform raw XML data into formatted HTML tables, reports, or other text documents. It matches patterns using XPath and outputs transformed content directly in the browser without writing manual backend conversion scripts.

Key XSLT Directives

  • <xsl:template match="/">: Matches the root node of the XML source document.
  • <xsl:for-each select="catalog/bike">: Iterates through each repeated node.
  • <xsl:value-of select="name"/>: Extracts and injects the text value of a node.
  • <xsl:sort select="price" order="ascending"/>: Sorts records on output.
  • <xsl:if test="price > 180000">: Filters records meeting conditional logic.
SERVER SCRIPTING

PHP (Hypertext Preprocessor)

Robust server-side scripting language for backend logic, form processing, state management, and DB connectivity.

Tasks: 5, 6A, 6B, 7A, 7B, 8A, 8B, 10, 11, 12

Execution Architecture & Superglobals

PHP code executes strictly on the web server (Apache/Nginx/CLI). The client browser receives only the resulting HTML output, never raw PHP source code.

Key Superglobals & Lab Implementations

  • $_POST: Captures data submitted via HTTP POST requests without exposing sensitive credentials in the URL (Tasks 5, 6A, 7B).
  • $_GET: Retrieves URL query string parameters (e.g. ?q=101) used in live search and AJAX lookups (Tasks 11, 12).
  • $_SESSION (Task 6A): Server-side state persistence across multiple page requests. Must be initialized via session_start() before any HTML is sent.
  • $_COOKIE (Task 6B): Client-side persistence set via setcookie("user", "val", time() + 3600). Useful for tracking last login time.
How to Execute PHP:

Method 1: XAMPP / WampServer (Recommended for University Lab)

  1. Copy project folder into C:/xampp/htdocs/.
  2. Open XAMPP Control Panel and click Start on Apache & MySQL.
  3. Open browser at http://localhost/project/filename.php.

Method 2: Built-in PHP CLI Server

  1. Open terminal inside the directory containing PHP files.
  2. Run command: php -S localhost:8000
  3. Open browser at http://localhost:8000/filename.php.
DATABASE MANAGEMENT

SQL & Relational Databases (MySQL / MariaDB)

Standard language for database schema definition, data manipulation, and PHP MySQLi integration.

Tasks: 7A, 7B, 8A, 8B, 12

Relational Model & MySQLi Integration

Relational databases store information in normalized tables comprising rows (records) and columns (attributes). In PHP, the modern mysqli (MySQL Improved) procedural and object-oriented interfaces allow direct communication with the database engine.

The 5-Step PHP MySQLi Lifecycle

  1. Connect: $conn = mysqli_connect("localhost", "root", "", "lab_db");
  2. Verify: if (!$conn) die("Connection failed: " . mysqli_connect_error());
  3. Execute SQL Query: $res = mysqli_query($conn, "SELECT * FROM users");
  4. Fetch Result Rows: while ($row = mysqli_fetch_array($res)) { echo $row['name']; }
  5. Close Connection: mysqli_close($conn);
Managing MySQL in XAMPP:

Start MySQL in XAMPP Control Panel, then access the phpMyAdmin web dashboard at http://localhost/phpmyadmin to create databases, inspect tables, and execute raw SQL queries.

ASYNC COMMUNICATION

AJAX (Asynchronous JavaScript and XML)

Asynchronous client-server communication mechanism for dynamic partial page updates without reloading.

Tasks: 10, 11, 12

Core Definition & Purpose

AJAX is not a standalone programming language, but a web development pattern combining the browser's built-in XMLHttpRequest object with JavaScript and DOM manipulation. It enables web applications to send requests and receive server data asynchronously in the background, updating only specific page fragments without disrupting the user experience with full-page refreshes.

The 5 XMLHttpRequest ReadyState Phases

  • 0 (UNSENT): Client instance created; open() not yet called.
  • 1 (OPENED): open() method invoked with HTTP verb and target URL.
  • 2 (HEADERS_RECEIVED): send() invoked; HTTP status and headers available.
  • 3 (LOADING): Response body data is currently streaming and transferring.
  • 4 (DONE): Data transfer operation complete. Response fully ready for DOM insertion.
