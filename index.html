Scripting & Web Languages Reference

Definitions, architecture overview, and practical execution instructions for university lab coursework.

5 Core Technologies
HTML5 Markup & Structure

HyperText Markup Language

The standard declarative markup language that defines the logical structure and semantics of web pages using nested elements, tags, attributes, and input controls to construct the Document Object Model (DOM).

How to Execute HTML:
  1. Save source code with a .html extension (e.g. index.html).
  2. Double-click the file to open directly in any web browser (Chrome, Edge, Firefox), or launch via local static server (e.g. npx serve or VS Code Live Server).
  3. The browser engine immediately parses and renders the markup without requiring compilation or backend runtime.
CSS3 Presentation & Style

Cascading Style Sheets

A stylesheet language used to describe the visual presentation, color schemes, typography, Flexbox/Grid layouts, and responsive formatting of documents written in HTML or XML.

How to Apply / Execute:
  1. Save stylesheets with a .css extension (e.g. style.css).
  2. Link inside HTML <head> via <link rel="stylesheet" href="style.css">, or declare inline inside <style>.
  3. The browser CSS engine automatically computes selector rules and applies styles during layout tree rendering.
JavaScript Client Scripting

ECMAScript / Dynamic Scripting

A high-level, interpreted scripting language with first-class functions that delivers client-side interactivity, input form validation, asynchronous HTTP calls (AJAX), and dynamic DOM mutations.

How to Execute:
  1. Link in HTML via <script src="app.js"></script> before closing </body>, or run live in browser Developer Tools Console (F12).
  2. Run standalone CLI scripts via Node.js runtime: node script.js.
  3. The browser V8/SpiderMonkey engine interprets and executes code on load or in response to DOM events.
XML / DTD / XSLT Data Transport

eXtensible Markup Language

A platform-independent, tag-based markup language created to store and transport structured data hierarchically. Schemas are validated via DTD/XSD and visually styled using XSL Transformations (XSLT).

How to Validate & Render:
  1. Save data with .xml extension (e.g. catalog.xml).
  2. Declare DTD validation grammar using <!DOCTYPE catalog SYSTEM "catalog.dtd">.
  3. Attach stylesheet via <?xml-stylesheet type="text/xsl" href="style.xsl"?> and open in browser to render as formatted HTML.
PHP (Hypertext Preprocessor) Server-Side Scripting

Server-Side Web Processing & Database Integration

A robust server-side scripting language executed on the web server to generate dynamic page content, collect and validate form submissions via $_POST/$_GET, manage persistent state with cookies and sessions (session_start()), and execute SQL queries against relational databases (MySQL via mysqli).

How to Execute PHP (Requires Web Server Environment):
Method A: Using XAMPP / WampServer
  1. Place .php files into C:/xampp/htdocs/your_project/.
  2. Launch XAMPP Control Panel and click Start for Apache and MySQL.
  3. Open your browser and navigate to http://localhost/your_project/filename.php.
Method B: Built-in PHP CLI Server
  1. Open terminal in the project directory where PHP files reside.
  2. Start server: php -S localhost:8000
  3. Open browser at http://localhost:8000/filename.php.
  4. Note: Never double-click PHP files or open as file:/// URL.
